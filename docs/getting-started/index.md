# Get started

This tutorial builds the smallest useful Pilota program, then replaces its deterministic test
model with a real provider.

## What you will learn

1. Install Pilota and choose optional dependencies.
2. Describe one bounded task.
3. Define its result as a Python type.
4. Run the task deterministically.
5. Switch to OpenRouter without changing the application contract.

Pilota requires Python 3.11 or newer.
